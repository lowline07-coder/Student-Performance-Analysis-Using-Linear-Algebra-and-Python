This project analyzes student performance using Linear Algebra and Python. It includes vectors, matrices, PCA, LDA, SVD, and eigenvalue analysis to demonstrate applications of mathematics in Data Science and Machine Learning.
# Student Performance Analysis Using Linear Algebra and Python

## Project Overview

This project demonstrates the application of Linear Algebra concepts in analyzing student performance data using Python.

The project includes both theoretical understanding and practical implementation of important mathematical and machine learning concepts such as:

- Vectors
- Matrix Operations
- Norms and Dot Products
- Cross Product
- Projection of Vectors
- Determinants and Inverse Matrices
- Eigenvalues and Eigenvectors
- LU Decomposition
- Singular Value Decomposition (SVD)
- Principal Component Analysis (PCA)
- Linear Discriminant Analysis (LDA)

The analysis is performed on a dataset containing students' scores in multiple subjects.
